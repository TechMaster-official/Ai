────────────────────────────────────────────────────────────────
  ৩) RUNNING
────────────────────────────────────────────────────────────────

  Interactive chat mode:

      python main.py

  One-shot question:

      python main.py -q "your question here"

  Play 3D animation:

      python main.py --anim donut
      python main.py --anim cube
      python main.py --anim matrix
      python main.py --anim plasma
      python main.py --anim all

  Skip splash screen:

      python main.py --no-splash

  Disable all animations:

      python main.py --no-anim

  Custom API endpoint:

      python main.py --api "https://your-api.example/api"

  Show version:

      python main.py --version

  Show help:

      python main.py --help

────────────────────────────────────────────────────────────────
  ৬) TROUBLESHOOTING
────────────────────────────────────────────────────────────────

  Problem: python: command not found
  Fix    : pkg install python

  Problem: Permission denied
  Fix    : chmod +x main.py

  Problem: Box characters look broken
  Fix    : Install a Nerd Font in Termux via termux-styling,
           then set it in your terminal emulator

  Problem: No colors
  Fix    : Termux → settings → Colors → Default

  Problem: API timeout
  Fix    : Check internet: pkg install curl
           curl "https://deep-ai-api-by-tech-master.vercel.app/api/deep-ai?query=hi"

  Problem: Animation is slow
  Fix    : Use --no-anim flag, or reduce duration in code
